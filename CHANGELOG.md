# Changelog

## Initial public package — 2026-10-18

- Published the Raspberry Pi 3B+ / Batocera 42 integration developed and checked on the original console (v0.5 baseline).
- Added English beginner documentation, wiring, installation, troubleshooting, editing and Batocera setup guides.
- Included the earlier startup splash, scrolling names/titles, three-second launch animation and shutdown/restart screens.
- Added optional English OLED text and its pre-rendered startup image. Polish remains the default. English is locally tested, not yet hardware-confirmed.
- Included local tests, a GitHub Actions test workflow and font licensing.
- Settings-menu detection and individual game artwork are intentionally outside the scope.
